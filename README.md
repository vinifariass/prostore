# Prostore

Prostore é uma plataforma de ecommerce onde você pode vender qualquer coisa, controlar usuários, pedidos e acompanhar seus ganhos mensais.

## Tecnologias Utilizadas

- **Next.js** - Framework React para renderização do lado do servidor
- **React.js** - Biblioteca JavaScript para construção de interfaces
- **Prisma** - ORM para acesso ao banco de dados
- **Neon** - Banco de dados PostgreSQL serverless

## Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/prostore.git
   cd prostore
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Configure as variáveis de ambiente:
   - Crie um arquivo `.env.local` na raiz do projeto
   - Adicione as variáveis necessárias (consulte `.env.example` se disponível)

4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

5. Acesse [http://localhost:3000](http://localhost:3000) no seu navegador

## Funcionalidades

- **Gerenciamento de Produtos**: Cadastro, edição e remoção de produtos
- **Controle de Usuários**: Registro, autenticação e perfis de usuário
- **Gestão de Pedidos**: Acompanhamento de pedidos e status
- **Dashboard Financeiro**: Visualização de ganhos mensais e métricas de vendas

## Estrutura do Projeto

O projeto segue a estrutura padrão do Next.js com App Router:

- `/app` - Rotas e componentes da aplicação
- `/components` - Componentes reutilizáveis
- `/prisma` - Schema e configurações do Prisma
- `/public` - Arquivos estáticos
